## M2 playback session-state foundation

`PlaybackMachineState` 现显式持有 `PlaybackPhase`、`playbackSessionId`、`loadRequestId` 与恢复状态；store 的单调递增 `playbackIntentId` 让同曲重播也创建新的 `playbackSessionId`。URL、歌词与媒体生命周期结果都必须通过当前 session/load authority，旧 session、旧 load、伪造或复制 handle 均不能提交状态。

`PlayerController` 把精确 load handle 绑定到已装载 source，媒体事件以 `currentSrc` 优先、`src` fallback 归一化 source；source 不匹配时不暴露 context。`timeupdate`、`durationchange` 与 `ended` 继续经过 runtime authority guard，重复的当前 `ended` 只接受一次，single mode 只产生一次 replacement load/play。

现有单次远程非试听媒体恢复、长暂停刷新、URL-age 刷新、trial/local 分支与 quality reload 行为已保留。此 foundation 不包含 pending/committed audio owner separation、gapless、crossfade、Audio Graph recovery、stalled probes、输出路由/设备、fades 或 dual deck；上述能力状态不变。Sidecar API 仍为 `legacy-frozen`，本批没有切换、嵌入或宣称完成开发中的 `MineRadio-api` / Rust API。
